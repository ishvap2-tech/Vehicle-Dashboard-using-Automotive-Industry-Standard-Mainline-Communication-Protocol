🚗 Vehicle Dashboard Using Automotive Industry Standard Mainline Communication Protocol

📌 Project Overview

This project focuses on developing a Vehicle Dashboard System using the Automotive Industry Standard Mainline Communication Protocol (CAN – Controller Area Network).

The system uses LPC2129 microcontrollers to establish communication between different automotive components through the CAN protocol. It monitors vehicle-related parameters using sensors and controls output devices to demonstrate an automotive dashboard application.

The project integrates CAN communication, temperature monitoring, and servo motor control to demonstrate real-time communication between automotive electronic control units (ECUs).

🛠️ Components Used

Component| Description
LPC2129 Microcontroller (3 Nos.)| Main controller for processing and CAN communication
CAN Protocol| Communication between microcontrollers
Servo Motor| Demonstrates motor/actuator control
LM35 Temperature Sensor| Measures temperature
CAN Interface| Enables CAN bus communication

⚙️ Technologies Used

- Embedded C Programming
- LPC2129 ARM7 Microcontroller
- Controller Area Network (CAN)
- Sensor Interfacing
- Servo Motor Interfacing
- Microcontroller Communication

🔄 Working Principle

1. Three LPC2129 microcontrollers are used to perform different control and communication functions.
2. The LM35 temperature sensor measures the temperature.
3. The temperature data is processed by the microcontroller.
4. CAN communication is used to transfer data between the microcontrollers.
5. The received data is processed by the corresponding controller.
6. The servo motor is controlled based on the programmed control logic.
7. The system demonstrates communication and coordination between multiple automotive electronic control units.

🎯 Project Objectives

- To understand CAN communication in automotive applications.
- To establish communication between multiple LPC2129 microcontrollers.
- To interface the LM35 temperature sensor with a microcontroller.
- To control a servo motor using embedded C programming.
- To demonstrate the working of a basic automotive dashboard system.
